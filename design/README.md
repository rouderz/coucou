# Design references

Screenshots of Lumo as it should look, rendered from the app's own code with the dev pages in
`windows/dev/` (`island.html`, `faces.html`, `greeting.html`, `upload-preview.html`, `icon.html`).
Visual changes should keep matching them — or update them in the same pull request.

| File | What |
|---|---|
| `captures/characters-states.png` | Lumo, Bao, Pip, Nube and Tecla in each state: idle, working, thinking, question, approval, error, finished, sleeping |
| `captures/island-main-base.png` | island design C: the character rail and the main character's base |
| `captures/island-github.png`, `island-whaticket.png` | an integration's character on its own base |
| `captures/island-character-chat.png` | an integration's character answering about what it handles |
| `captures/greeting.png` | the launch greeting: Lumo waves a tentacle |
| `captures/drop.png` | a dropped file, held by Lumo |
| `captures/app-icon.png` | the app icon |
