FAQ

The system says it can’t verify the app

Builds aren’t signed yet. On a Mac, the first time: System Settings → Privacy & Security → Open Anyway. On Windows: SmartScreen → More info → Run anyway. Only once.

Lumo doesn’t show my Claude Code sessions

Settings → Claude Code → Install hooks, review the changes, confirm, then start a new Claude Code session.

The chat doesn’t answer

Check that Claude Code is installed and signed in (Settings → Chat → Engine), or add an Anthropic API key there.

No sound

Check the speaker icon in the island header and the volume in Settings.

How do I uninstall?

Settings → Claude Code → Uninstall (removes only Lumo’s hooks), then quit the app and delete it. Optionally delete its folders (see the privacy policy).

Preguntas frecuentes

El sistema dice que no puede verificar la app

Las versiones aún no están firmadas. En Mac, la primera vez: Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente. En Windows: SmartScreen → Más información → Ejecutar de todas formas. Solo una vez.

Lumo no muestra mis sesiones de Claude Code

Ajustes → Claude Code → Install hooks, revisa los cambios, confirma y abre una sesión nueva de Claude Code.

El chat no responde

Comprueba que Claude Code está instalado y con sesión iniciada (Ajustes → Chat → Motor), o añade ahí una clave de la API de Anthropic.

No hay sonido

Revisa el icono del altavoz en la cabecera de la isla y el volumen en Ajustes.

¿Cómo lo desinstalo?

Ajustes → Claude Code → Uninstall (quita solo los hooks de Lumo), cierra la app y bórrala. Si quieres, borra también sus carpetas (ver la política de privacidad).
